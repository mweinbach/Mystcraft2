# BuildCraft items and blocks that no recipe makes. The `everyItemCraftableOrListed` GameTest
# (RecipeAuditTests, run on Forge and Fabric) reads this file and fails when
# - a registered buildcraft item is neither the result of a recipe the server loaded (crafting,
#   smelting, assembly, integration or any other type, including the facade assembly) nor listed here;
# - a buildcraft block has no item and is not listed here, unless it is a fluid block whose bucket
#   is a buildcraft item (the bucket is audited instead);
# - a listed id is not registered, or a listed item is now craftable, so this file only shrinks.
#
# Format: <kind> <id>  # reason (required); <id> is a buildcraft registry path.
#   creative  no survival source: creative tab and commands only
#   obtained  made in survival, but not by a recipe (the reason names how)
#   block     a block with no item
