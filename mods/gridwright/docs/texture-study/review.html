GRIDWRIGHT / ART DIRECTION 01

A workshop built into Minecraft.

Stone for the first generator. Riveted iron for machines. Copper joints and small crystal accents. Original 32x32 textures, inset machine bodies, open rotors and a low portal basin. The resource pack is a partial study for review.

The right-hand block renders use the proposed models. Offline renders are not game screenshots. The optional pack changes appearance only. Smaller models retain the current hitboxes and occlusion until a gameplay PR updates them.
