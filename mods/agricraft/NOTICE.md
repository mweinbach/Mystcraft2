# AgriCraft provenance

This is an unofficial Minecraft 1.19.2 port of AgriCraft by InfinityRaider and Ketheroth, with
contributions from the AgriCraft contributors. It is not an official AgriCraft release; please report
port problems to this repository, not to AgriCraft.

The code, assets and data come from https://github.com/AgriCraft/AgriCraft, branch `1.20.1`, revision
`e16ced0b88dd675487234a95fda63736c96edfbd` (AgriCraft 4.0.6 for Minecraft 1.20.1). AgriCraft is
distributed under the MIT License; its license is retained as `LICENSE`, and author attribution is
retained here and in the mod metadata.

- `src/main` is upstream's `common/` module, `src/fabric` its `fabric/` module and `src/forge` its
  `forge/` module, each adapted to Minecraft 1.19.2, Forge 43.5.0 and Fabric API 0.77.0. The changes are
  listed in `docs/PARITY.md`.
- Upstream generates its plant, soil, mutation, fertilizer, recipe, loot, tag and model JSON with a
  Forge datagen run and does not commit the output. The generated `data/`, `datapacks/`,
  `resourcepacks/` and model files here were taken unchanged from the published AgriCraft 4.0.6 jars
  (Modrinth `AgriCraft-fabric-1.20.1-4.0.6.jar`, SHA-256
  `85a608a8352b42aab7fa9bcd7b856f17994217319aba5031748e8da7cf075b09`, and `AgriCraft-forge-1.20.1-4.0.6.jar`,
  SHA-256 `7f6cf2bcff0d4dd432c1c8a6c6b201c0114829b456506abdfaa29f67cc89992f`; their data is identical), apart from
  the pack format numbers and the removal of torchflower content, which 1.19.2 does not have.
- Port-specific code written for this repository (the 1.19.2 data-registry loader and sync, the
  `AgriGuiGraphics` drawing facade, the loader adapters' 1.19.2 event wiring, GameTests and EMC data) is
  also MIT-licensed.

The Fabric artifact bundles MixinExtras 0.4.1 by LlamaLad7 under the MIT License for the lava-bucket hook.
Its license is retained in the nested dependency JAR and in `licenses/mixinextras-LICENSE.txt`.

Distribute this notice, the license and the corresponding port source with redistributed builds.
Source JARs are generated by the build.
