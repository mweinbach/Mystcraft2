# EMC values for `agricraft`

Generated by `python3 scripts/emc.py generate` from `policy.json` and `registry.txt`; do not edit. See [docs/emc.md](../../../docs/emc.md) for the method and the ProjectE/Item Alchemy loader notes.

25 registered items: 3 excluded, 7 explicit, 15 recipe. `recipe` values are derived from crafting, smelting, stonecutting and smithing recipes, `tag` values come from the EMC mod's own tag defaults, and `explicit` values are listed below. Full per-item values are in `values.json`.

Resource crops (coal, copper, diamond, emerald, quartz, netherite, amethyst) are a farming source like any crop, not a transmutation loop: their seeds carry no EMC, and each resource item is worth a ninth of the vanilla item its nine-piece recipe makes, rounded up, so crafting nine never gains. The magnifying-helmet recipe only adds an NBT flag to a helmet the player already has.

## Excluded (no EMC)

| Item | Why |
| --- | --- |
| `agricraft:seed` | One item for every plant: the species and six stats live in NBT, which transmutation does not copy, and mutations breed rare plants from common seeds, so any value would let cheap seeds be bred into EMC. |
| `agricraft:debugger` | Creative-only developer tool with no recipe. |
| `agricraft:journal` | Crafted from a writable book and any seed, and records researched plants in NBT; a transmuted copy would be a blank journal, and pricing it on the seed tag would price AgriCraft seeds through the back door. |
