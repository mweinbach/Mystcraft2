# Classic Huge Trees adapter

`ClassicHugeTrees` is a mechanical shared1.19.2 adapter of pinned official `WorldGenMystBigTree` and `MapGenAdvanced`, revision9bc8ddc061845df0cd5ea47f4fdef773cff786ae, LGPL-3.0-only. It preserves the source eight-chunk neighbor search, seed expansion/RNG call order and50% per-source-chunk attempt. Roots originate atY4..11; canopy bases areY128..180 with height40..69. The source2×2 trunk, leaf-node/branch/root equations, half-block rounding, approximate square root andY0..254 placement bounds remain. Logs/leaves are fixed oak, as in the original symbol; it consumes no material parameter. Bedrock cannot be replaced, but other terrain/liquids can be overwritten as in the source.

Modern oak leaves initialize distance1 and persistent=false, rather than the modern default distance7 that would cause immediate random-tick decay without a source-style initial leaf check. Neighbor updates can subsequently recompute normal leaf distance. This is an explicit modern block-state adaptation, not a claim of identical leaf-decay timing.

A test-only extraction independently compiled the original generator/base against primitive chunk storage and compared the production adapter's final block kinds over18chunk snapshots: three seeds, three origin/negative/distant positions and both empty/stone-with-bedrock input. All1,179,648 cells matched exactly, totaling11,252logs and15,214leaves. Evidence: `work/huge-tree-reference/comparison.log`. This comparison intentionally excludes modern leaf-distance state, and does not substitute for live loader/world-generation verification. Instantiate a generator per call, as for the other mutable classic carver adapters.
