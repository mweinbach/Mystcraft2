# Classic book screen parity

The shared Forge/Fabric screen follows the 1.12 `GuiElementBook` layout at 327 by 199 logical pixels, using original cover, left page, link-panel page, and full right-page artwork. Descriptive books receive the original gold cover borders. The first opening shows the title, authors, and link panel; later pages follow stored order and duplicates, and the final index shows the blank back cover. The counter retains classic zero-based index/page-count semantics.

Pages can be turned by clicking either page, using arrow keys or the configured left/right keys, and with focusable navigation controls. Home returns to the title/link page; End opens the back cover. Inventory and Escape close the screen. The linking panel is a focusable widget, disabled when unavailable, and exists only on the title/link page; clicking its region never accidentally turns the page. Scaling applies equally to drawing and pointer hit tests.

Symbol pages draw the original component atlas at the original four-word positions from the classic symbol poems and word definitions. Unknown symbols use the classic unknown glyph and retain their raw identifier in the tooltip. This uses the atlas directly, so a replacement resource-pack atlas is honored. The full-screen read-only presentation snapshot comes from the server; navigation never changes the canonical book, and link requests carry only the server-issued token. Ordinary page-item tooltips show gameplay information and unknown-symbol warnings; raw symbol IDs appear only with advanced tooltips.

The core destination panel distinguishes available, unavailable and visited destinations with the source gradient/effects; Following glint, Disarm lightning and hurt tint also have implemented presentation paths. The pinned physical renderer uses a fixed open pose rather than a book-opening animation. LookingGlass live destination cameras were an optional external integration, and editable custom cover colors were not found in the pinned core renderer. Neither should be counted as missing built-in book gameplay. See [book-presentation-parity.md](book-presentation-parity.md) for exact source boundaries and label/receptacle settings.

The desk additionally embeds the original book at 90×50 logical pixels with independent page navigation and a single-click link panel. Its server menu binds the exact target object and full snapshot, current desk inventory, menu identity and reach; replaced or mutated targets cannot activate an old view. Before allocation, paid writing fills only the first existing blank descriptive-book page; allocated canonical pages and frozen worlds are not rewritten. See [page-browser.md](page-browser.md) for the complete desk/collection transaction contract.

Remaining boundaries include seasonal/addon glyph renderers, arbitrary addon custom word colors/atlases and full contextual tooltip extensions. Dynamic registry biome/fluid pages now compose the original atlas in GUI, hand and world rendering; see [dynamic-symbol-pages.md](dynamic-symbol-pages.md). All 145 static catalog entries have source compiler/runtime paths, but rendering a glyph does not prove every effect or combination matches 1.12.

Build, dedicated-server and graphical observations apply to their named artifacts. Earlier screenshots are historical evidence and do not validate every later UI, terrain or celestial change. Current packaged runtime, restart and graphical results are maintained in [validation.md](validation.md); this source comparison does not promote an earlier screenshot into evidence for a later artifact.
