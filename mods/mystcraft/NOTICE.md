# Classic Mystcraft provenance

This is an unofficial, incomplete Minecraft 1.19.2 port of classic Mystcraft by
XCompWiz. It is not a release of Mystcraft 2 and does not implement its new
stability design.

The reference implementation and imported classic art come from
https://github.com/Mystcraft/Mystcraft-Legacy, branch `1.12/develop`, revision
`9bc8ddc061845df0cd5ea47f4fdef773cff786ae` (Minecraft 1.12.2, Mystcraft 0.13.7.06).
The upstream repository distributes its code and resources under GNU LGPL v3;
its license is retained as `LICENSE`. Original author attribution is retained
here and in mod metadata. Imported textures are adaptations of the upstream
`src/main/resources/assets/mystcraft/` assets (textures, GUI art and sound).
`docs/asset-provenance.md` records exact imported paths and SHA-256 hashes. Resource locations and
models were adapted for Minecraft 1.19.2; original art is not newly authored.

The linking implementation, recipe, and block interactions were rewritten for
Forge 43.5.0 and Fabric using that source as the behavioral reference. This is not binary
or save-format compatibility with 1.12. Modern engine adaptations, optional external integrations and validation limits are explicit;
see `docs/classic-parity.md` and `README.md`.

The original repository scaffold came from Mystcraft/Mystcraft2 revision
`55ff806e6229b932542ba1bd1c9a7096b24dea73`. Its README and CLA workflow remain
archived as `UPSTREAM.md` and `upstream/cla.yml`.

Distribute this notice, the license, and the corresponding port source with
redistributed builds. Source JARs are generated by the build.

The Fabric artifact bundles MixinExtras 0.4.1 by LlamaLad7 under the MIT License for composable hooks that coexist with other mods. Its license is retained in the nested dependency JAR and in `licenses/mixinextras-LICENSE.txt`.
